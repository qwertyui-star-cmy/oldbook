# 文本精准定位古籍

本地打开：

```text
.\start.cmd
```

首次在新电脑或重新克隆仓库后，先在项目目录运行：

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

启动程序会依次尝试项目内 `.venv`、Codex 工作环境和系统 Python；只有依赖检查通过后才会打开页面。若后台启动失败，错误会写入 `.cache/server.stderr.log`，不会再打开一个无法使用的空页面。

默认地址：

```text
http://127.0.0.1:8787/index.html
```

这个工具的目标是：保留影印 PDF 的原样画面，同时把可靠文本放回接近原书排版的位置，让 PDF 可以搜索、复制。

当前可用能力：

- 导入 PDF
- 导入 TXT、HTML、EPUB 或网页文本
- 自动判断材料状态和页面样子
- 先试一页，生成定位预览
- 输出单页试运行 PDF
- 后台生成整本 PDF
- 逐页保存中间结果，任务中断后可继续
- 页面只输出最终 PDF，不把内部报告露给用户
- 大型 PDF 支持浏览器分段读取，不会整本一次塞进内存
- 最终 PDF 通过页数、复制文字和代表页画面检查后才会发布
- 每页写入一条连续且与权威来源一致的文字流，搜索不受竖排换行影响
- OCR 与来源对齐会归一繁简、异体字和标点；成品 PDF 保留权威原文字形，避免复制时混入重复的繁简文本
- 本页页首确定权威文本起点，次页页首反推本页终点；本页页尾 OCR 只作非阻断交叉验证
- 根据扫描画面的页边文字，对齐 TXT、HTML、EPUB 或网页校准文本；不信任 PDF 原有 OCR 层
- EPUB 严格按 OPF 书脊顺序读取，并保留上传原件用于恢复和复核
- 不按平均字数估算分页，也不使用整页 OCR 反推权威文本范围
- 不能由相邻页首页唯一锁定的页面、跨章节混排页和最后一页，在权威页处理结束后统一进行本页整页 OCR
- 最终 PDF 可以同时包含权威文本页、纯 OCR 页和空白页；纯 OCR 页不会阻止整本发布
- 页边 OCR 与整页 OCR 保留多进程处理，并按 CPU 和可用内存自动限制并行数
- 最终整本 PDF 使用 QPDF 线性化，适合大文件分段下载和快速网页读取
- 整本任务可暂停；再次生成会从已完成页继续
- 可手动清理当前任务缓存

离线说明：

- 使用本地 PDF 和本地文本时，可以断网运行。
- 只有选择“网页链接”作为文本来源时，需要联网抓取那份网页文字。
- 这个产品不必须接入 AI。核心能力可以用本地解析、版面识别、页文对齐和 PDF 写入完成。
- AI 适合作为增强功能，例如解释异常页、辅助判断版本差异、给出人工修正建议。

说明：

- 应用使用独立端口 `8787`。
- 原来的阅读应用使用 `8765`，两者互不占用。
- 输出文件放在本应用的 `.cache/text-layer-jobs` 目录。
- 整本导出的文件名是 `text-positioned-full.pdf`。
- 大型整本输出在网页中默认下载，不直接交给浏览器内置阅读器打开。
- 每次启动会自动清理超过 7 天的临时文件；不会删除最终 PDF。
- 重复打开启动程序不会强行关闭正在运行的整本任务。
